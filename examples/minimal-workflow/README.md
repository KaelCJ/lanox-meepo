# Minimal workflow example

This example is synthetic and intentionally contains no real repository, user, customer, or session data.

```text
需求：为示例服务增加健康检查接口。
约束：只写方案，不修改业务代码。
验收：说明路径、响应和验证命令；明确未执行的验证。
```

## Expected workflow record

```text
目标：记录健康检查接口的需求和验收标准
范围：仅方案与记录，不修改业务代码
已完成：创建工作项，保存原始需求
未完成：实现、测试和真实端到端验证
下一步：用户确认方案后再进入执行
```

A real run must preserve the same distinction between a planned action and an action that actually happened. Do not replace this synthetic example with a production transcript.
