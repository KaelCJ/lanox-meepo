# 创建工作项方法

## 索引前置

- 索引齐全时，执行 `validate`。
- 目标空间没有索引和工作项时，执行 `init`。
- 索引不全或校验失败时停止，不自行补齐或覆盖。

## 创建步骤

1. 查重：按目标和关键词搜索当前及已归档工作项，阅读相似项的 README 判断是否重复；关键词没搜到，不代表没有重复项。确认重复时返回已有项的状态和链接并停止，不创建或修改；无法确定时暂停创建，列出相似项请用户确认。
2. 生成 ID：调用索引工具 `new-id`。
3. 创建目录：在工作项根下新建 `YYYY-MM-DD_<ID>_<短名>/`，ID 原样使用；确认路径未超出工作项根且目录不存在。
4. 创建骨架：新建 `需求/`、`方案/`、`执行/`、`测试/` 四个目录，按 [工作项 README 模板](../工作项README模板.md) 编写根 README。
5. 登记索引：调用 `create --id <ID>`，填写标题和 README 相对路径；类型、产品和优先级按用户指定值填写，未指定时使用工具默认值。
6. 保存原话：按 [原始需求方法](../方法/原始需求方法.md) 创建 `需求/原始需求.md`，记录用户原话及本次实际响应摘要。
7. 核对结果：回读新建文件和索引记录，执行 `validate`，确认编号、路径和内容一致。

普通创建只生成以下内容：

```text
YYYY-MM-DD_<ID>_工作项名称/
├── README.md
├── 需求/
│   └── 原始需求.md
├── 方案/
├── 执行/
└── 测试/
```

## 完成与交接

- 创建完成后报告入口并停止。
- 用户要求创建后继续处理时，先完整读取新建 README，再读取 [继续工作项方法](继续工作项方法.md)。
- 任一步失败时保留现场，说明已完成内容和失败位置，不继续后续处理或宣称创建成功。
