# 继续工作项方法

本方法用于继续、查看、修改、设计、实施、验证、交付、完成或重新处理一个已经存在的工作项。

1. 用户只说“继续 Rxxx”时，以 README“当前停点”中的下一步为入口；下一步缺失、存在多个互斥选择或仍需 Human 决定时再请求补充。
2. 只读取当前动作真正需要的需求、方案、执行、测试、源码、配置或运行事实。建立完整核心记录时读取 [建档方法](建档方法.md)；其他任务使用当前项目、适用 Skill 或 Agent 已有的方法完成，不由本 Skill 重复定义专业方法论。
3. 仅查看或说明时保持只读，回答后结束，不加载更新方法，不修改文件或索引。生产动作只执行用户当前授权的目标，不因“继续”自动获得发布、发送、迁移或其他外部副作用授权。
4. 非只读动作完成或出现真实失败后，读取 [更新工作项方法](更新工作项方法.md)，只把本次已经发生的事实同步到工作项；不得提前把计划写成完成。

非只读动作部分失败时保留现场，更新真实停点并报告恢复入口，不静默清理或宣称成功。
