# 认知拉齐方法

用于创建和维护 `需求/认知拉齐.md`。

只保留换一个 Agent 后仍需知道的高价值理解：

- 当前目标、边界、职责和关键结构；
- Human 认可或纠正过的 Agent 总结；
- 容易反复误解的概念、反例和判断原则。

写清当前理解、依据以及是否得到 Human 确认。未确认内容标为待确认，不能改变正式需求。

状态、流程或关系仅靠文字难以拉齐时，使用合适的图示表达；图用于确认共同理解，与正文一起维护。

Human 纠正旧理解时更新当前结论；旧内容只有在解释演进确有价值时才保留并标明已被替代。

不保存完整聊天、临时计划或普通过程信息，也不替代 `原始需求.md`、`需求.md` 或实施授权。
