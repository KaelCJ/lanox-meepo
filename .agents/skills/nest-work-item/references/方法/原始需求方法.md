# 原始需求方法

## 1. 格式

```markdown
# 原始需求

## YYYY-MM-DD｜简短主题

### 用户原话
> ...

### Agent 响应摘要
...
```

## 2. 写什么

- 用户原话逐字记录；无法取得原文时标明“摘要”，不得补造。
- Agent 响应摘要只写实际结论、已执行动作、结果、失败和未完成边界。
- 本轮补充、纠正或替代旧记录时，写明关系。

## 3. 怎么追加

- 按对话顺序追加；同一意图的连续消息可以合并，改变目标、范围或授权时新建一条。
- 追加前先去重；实际动作完成后再写对应的 Agent 响应摘要，不无痕改写历史。

## 4. 怎么清理

- 删除重复记录、临时进度、无独立恢复价值的过期 Agent 摘要和无关内容。
- 用户原话、纠正、授权、关键决定和独有失败事实不得作为过期内容删除；已失效时标明被替代，无法判断时保留。
