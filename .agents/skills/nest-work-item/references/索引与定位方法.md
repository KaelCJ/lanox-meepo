# 索引与定位方法

## 索引位置

工作项根为目标空间的 `.workspace-assistant/10-工作项/`：

- `current.json`：当前工作项。
- `archive.json`：已归档工作项。
- `index.schema.json`：索引格式定义。

## 工具用法

使用本 Skill 的 `scripts/work_item_index.py`，需要 Python；生成 ID 还需要 Java 21 或以上版本。

```text
python "<Skill目录>/scripts/work_item_index.py" --root "<目标空间>/.workspace-assistant/10-工作项" <命令>
```

- 按编号定位：`resolve <ID>`。
- 按名称搜索：`find "<关键词>"`；搜索归档项加 `--scope archive`。
- 创建前查重：`candidates "<关键词>"`，搜索当前和已归档工作项。
- 写入前后校验：`validate`。

命令参数不清楚时查看 `<命令> --help`。一般通过查询定位，不整份读取索引。

## 定位后处理

从查询结果取得唯一入口，完整读取工作项 README，再按当前任务读取必要文件。

找不到工作项、结果不唯一、入口不可用或工具报错时，停止并说明问题，不自动修复或创建。
