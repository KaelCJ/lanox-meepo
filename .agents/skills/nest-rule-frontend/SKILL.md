# Frontend Rule 加载

1. 首次应用前读取 [当前生效的唯一规则正文](references/rules.md) 的目录和 `通用` 章节。`references/rules.md` 统一承载 FE-001～FE-014；旧迁移对照不参与加载。
2. 按当前任务事实追加读取专题，未命中的专题不读取：
   - 字体、字号、行高、字重、字距、数字、代码、截断或字体资源 → `排版`；
   - 公共、复用、统一、组件化，或两个以上真实消费者共享同一交互/协议机制 → `公共能力`；
   - HTML 页面新增、移动、重命名、删除，或涉及 URL、重定向、静态映射、页面鉴权 → `页面入口`。
   多个事实同时命中时合并读取；只改不涉及这些专题的前端内容时只读 `通用`。
3. 读取每个选定章节至下一个同级或更高层标题，不能用目录行或单条规则代替正文。专题是否命中、章节边界或文件完整性无法确认时，回退为完整读取 `rules.md`；文件缺失、为空、不可读、未完整加载或规则冲突时，停止受影响的设计、写入和结论，不用历史副本猜补。
4. 记录本次读取的章节和 `rules.md` 文件状态（优先 SHA-256）。同一有效上下文且正文、适用范围未变化时复用；压缩、接续、文件变化或无法确认仍完整可用时重新读取。
5. 在首次设计、写入或审计结论前应用已加载规则。加载规则不扩大用户授权，不授权批量迁移或清理；委派前端工作时要求子 Agent 自行使用本 Skill，不复制正文。
