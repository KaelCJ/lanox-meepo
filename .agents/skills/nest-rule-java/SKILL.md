# Java Rule 加载

## Rule 加载

1. 本 Skill 命中后，在当前有效上下文第一次需要执行受 Rule 约束的操作前，完整读取 [唯一规则正文](references/rules.md)。
2. `rules.md` 发生变化时，不得继续复用变化前的 Rule，必须重新完整读取。
3. 上下文压缩、会话接续，或无法确认当前上下文仍完整包含 `rules.md` 时，必须重新完整读取。
4. 无法读取、读取结果为空、不完整或存在明显冲突时，停止受影响的工作，不使用模型常识补齐缺失规则。

## Rule 应用

1. 当前有效上下文中已完整加载且文件未变化时，可以复用已加载 Rule。
2. Rule 是约束，不扩大用户授权；加载 Rule 不代表可以自行创建工作项、执行验证、迁移代码或改变用户未授权的范围。
3. Rule 与项目事实冲突、事实不足以支持结论，或 Rule 要求人工确认时，停止受影响结论并向用户确认，不得自行推断。

## 子 Agent 委派

委派相关工作时，要求子 Agent 自行使用本 Skill 并按本协议加载 Rule；不得复制 `rules.md` 正文到委派提示中。
