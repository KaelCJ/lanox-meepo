# 查看代办

## 执行

1. 定位 `.workspace-assistant/10-工作项/current.json` 与 `archive.json`；两者都不存在时直接回复“当前空间尚未初始化工作项，暂无代办；需要创建时使用 `$nest-work-item`”，保持零写入。只缺一份、格式错误或相互冲突时报告索引损坏，不猜测。
2. 使用 `nest-work-item/scripts/work_item_index.py list` 读取 `current.json` 的全部记录，不再按 `status` 过滤。默认最多 5 个，用户可指定 `0`—`100`，其中 `0` 表示全部。
3. 每项展示编号、短名、用户优先级、当前摘要和 README 入口。当前摘要从对应 README 的“当前简介”读取；没有该章节时使用标题后的简介，仍为空则省略，不从旧看板猜测。
4. 用户优先级只接受 `P0/P1/P2/P3/未设置`；按 P0 至 P3 排序，`未设置` 保持索引顺序。已初始化但 `current.json` 为空时回复“当前没有工作项”。
5. 只说明建议先处理什么及原因，不修改索引、优先级、文件归属或工作项内容。

用户选中某项后，再按用户本次问题定向读取相关产物；不加载额外流程状态或控制文档。
